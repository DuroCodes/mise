The recipe box you host yourself.

Mise keeps a household's recipes, meal plan, shopping list and pantry in one place. It runs in a single Docker container on a machine you own, and the code is open source.

Install with Docker Source on GitHub

Nothing to sign up for here. The first visit to your own copy creates the admin account.

Recipes

Save a recipe from wherever you found it.

Paste a link from a recipe site, TikTok or Instagram and Mise pulls out the ingredients and steps. Moving from Paprika or Mealie? Upload the export and the whole library comes with you.

Video imports read the caption and any text on screen. Add a speech-to-text key for the ones where the recipe is only spoken. On Android, you can share a link to Mise from any app.

Scale and convert
Change the servings and every amount follows. Switch between metric and US units, oven temperatures included.
Timers in the steps
A duration such as “simmer 10 minutes” becomes a button. It counts down and chimes when the time is up.
Search and sort
Search titles, ingredients and steps. Filter by tag or favorites. Sort by quickest, top rated or recently cooked.
Collections
Private groups of recipes, such as Thanksgiving or weeknight dinners.
Ratings and a cooking log
Everyone rates recipes and logs when they cooked them, with notes.
Share links
A read-only link to one recipe, for someone without an account. Turn it off whenever you like.
Nutrition estimate
Per serving, worked out from a built-in food table. Nothing is sent anywhere.
Print layout
A clean page for the recipe you want on paper.

Plan

Plan the week once.

Drag recipes onto days, or tap Add on a phone. One button turns the whole week into a shopping list.

With notifications on, a note arrives at 6pm about tomorrow's meals.

Shopping

One list, in the order you walk the store.

Add a recipe or a whole week. Matching ingredients are added together, with units converted when they are compatible, so three recipes that need olive oil give you one line.

Save the stores you shop at with their sections in walking order. Pick a store and the list sorts itself into that route.

Scan and shop
Scan barcodes with the phone camera to check items off. Product names come from Open Food Facts.
No signal needed
The list works offline and syncs when you are back online.
Done shopping
Tell Mise how much of each item goes into the pantry, and it moves it there.

Pantry

Cook from what you already have.

Keep track of what is in the house, with use-by dates. “What can I make” ranks your recipes by how much of each you already have, and puts whatever is missing on the shopping list.

A heads-up arrives at 9am when something needs using soon.

Admin

It all stays on your machine.

One folder
The database (SQLite) and uploaded images live in a single data folder. Mount it wherever you keep things you care about.
Backup and restore
Admins download a zip of everything: recipes, images, logs, plans, lists and a copy of the database. Restore it from the same page.
Accounts you control
The first visit creates the admin account. After that sign-up is closed, and admins add everyone else.
Installs like an app
Add it to a phone's home screen. Recipes you have opened stay readable offline.
Notifications
Timers that ring with the phone locked, plus the pantry and meal plan reminders. Off until you turn them on, per device.
AI is optional
Off unless you set an API key. It works with Anthropic, OpenAI, OpenRouter, or a local model through Ollama, and turns pasted text, a photo of a recipe card or a receipt into something Mise can use.

Four themes come with it, and this page is wearing one of them. Pick another.

Install Mise

About 2 minutes. Serves the whole household.

You need

  • A machine that stays on. A home server, a NAS or a Raspberry Pi will do.
  • Docker, with Compose.
  • An HTTPS address, if phones are going to install it or get notifications (optional)

Steps

  1. 1

    Make a folder and fetch the compose file. 

    mkdir mise
cd mise
curl -fsSL -o compose.yml {{raw}}/main/compose.yml
    See what is in compose.yml 
    {{compose}}
  2. 2

    Start it.

    docker compose up -d
  3. 3

    Open localhost:3000 and create the admin account. Three example recipes are waiting, including the shakshuka from the top of this page.

Serving it from a domain? Set BETTER_AUTH_URL to the public address in compose.yml. The settings reference covers ports, the data folder, AI providers and the rest.

Mise is open source, and inspired by Mealie.
